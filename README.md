# Pose Play v0.4 (RAZ Corp)

Phone = camera + tracking (up to 4 people), TV = menu + games. Or the TV alone with its own camera.

Menu: RAISE a hand over a game for 1 second (a resting hand never selects), or remote LEFT/RIGHT + OK.
BACK = menu. UP = debug info, DOWN = switch TV camera Camera2/UVC.
Phone buttons: Wi-Fi, TV IP, Bluetooth, Flip camera, Rotate (auto / landscape / portrait). Buttons hide when connected - tap the screen to show.
Squats need knees in view (portrait phone + step back). Several players: use landscape.
If the app ever crashes, the next launch shows "Last crash: ..." on screen - send it to me.

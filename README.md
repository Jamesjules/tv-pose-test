# Pose Play v0.5 (RAZ Corp)

Phone = camera + tracking (up to 4 people), TV = menu + games. Or the TV alone with its own camera.

Menu: RAISE a hand over a game for 1 second, or remote LEFT/RIGHT + OK. UP = debug info, DOWN = switch TV camera Camera2/UVC.
In a game: hold a hand over the pause button (top-right) for ~1 s, or press OK / BACK on the remote, or tap "Pause" on the phone.
Pause menu: Resume / Restart / Main menu (hand-hover or remote). BACK on the results screen = main menu.
Phone preview is mirrored like a selfie mirror. Phone buttons: Wi-Fi, TV IP, Bluetooth, Flip, Pause, Rotate (hide when connected - tap screen).

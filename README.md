# Pose Play v0.6 (RAZ Corp)

Phone = camera + tracking (up to 4 people), TV = menu + games. Or the TV alone with its own camera.

11 games: Bubble Pop, Fruit Slice, Meteor Dodge, Squat Race, Jumping Jacks, Sliding Puzzle, Memory Match,
Whack-a-Mole, Fruit Catch, Quiz Zones, Pose Match. Plus Settings (lite graphics, sound, TV camera Camera2/UVC, debug).

Menus (main, pause, results, settings): RAISE a hand - it moves a pointer relative to your body (works wherever you stand).
Hold the pointer over a button for 1 second. Remote: arrows + OK, BACK = pause / back.
In a game: hold a hand over the pause button (top-right), or OK / BACK on the remote, or "Pause" on the phone.
Puzzle and Memory also use the raised-hand pointer inside the game.

# Pose Play v0.3 (RAZ Corp)

Phone = camera + tracking (up to 4 people), TV = menu + games. Or the TV alone with its own camera.

Games (1-4 players, each person gets a color P1..P4): Bubble Pop, Fruit Slice, Meteor Dodge, Squat Race, Jumping Jacks.
Menu: hold a hand over a game for 1 second, or remote LEFT/RIGHT + OK. BACK = menu. DOWN (in menu) = switch TV camera Camera2/UVC.
Best scores are saved on the TV.

Link phone -> TV: Wi-Fi auto / TV IP (same router or phone hotspot), or Bluetooth if the TV supports it.
Install: adb install -r pose-play-camera2.apk (TV), normal install on the phone.
Tips: phone on a stand in landscape, 2-3 m back, whole body visible, good light. Players should stand side by side.
